## 2. 实现要点

- 头文件注释中的规则按 1→4 顺序实现；会话表满的判断早于白名单/策略判断。
- `PHONE_PREEMPT`：手机接入时把所有 `ALARM` 会话放入 `link_actions_t` 并从会话表移除；手机在线时拒绝白名单报警器。
- HELLO（`0x0041`，sender `0x03`）在配对窗口内把 `PHONE`/`PENDING` 提升为 `ALARM` 并加入白名单（重复不追加，满则断开）；窗口外断开。
- 所有超时比较写成 `(uint32_t)(now_ms - t) > LIMIT`（窗口关闭用 `>=`），容忍 32 位毫秒回绕。
- 被断开的会话立即置 `b_in_use = false`，之后的 `on_close` 被忽略。
- 无动态内存、无时钟调用、无 IDF 头文件。
