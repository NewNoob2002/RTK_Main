## 2. 行为与实现

- 启动顺序与任务要求一致；`store_init` 失败仅记录错误并继续（默认 SN、空白名单）。
- SN：优先 NVS；不存在/为空时用 `esp_read_mac(ESP_MAC_BT)` 后 2 字节生成 `"%02X%02X"`；失败回退 `"0000"`。蓝牙名 `"E1-Lite-<SN>"`，无换行。
- `link_mgr_init(&g_app_link, app_link_policy(), ...)`；`CONFIG_RTK_LINK_POLICY_CONCURRENT=y`（默认），可选 `PHONE_PREEMPT`。
- `alarm_src_init`、`cmd_disp_init`，填写 `info.sn`、`info.fw_ver = APP_VERSION_STR`。
- 链路任务：静态栈 6144 B、优先级 10、core 1；`bt_spp_poll_event(20 ms)` → OPEN/CLOSE/DATA/RX_DROP；每 100 ms `link_mgr_tick`；每 1000 ms 向 ALARM 会话推送 0x40（seq 每轮 +1）。
- OPEN：`link_mgr_on_open` → 执行断开动作 → 为接受会话分配常驻解析器（按 handle）；CLOSE 释放。
- DATA：循环 `bt_spp_read` 到 0，逐字节 `proto_parser_feed`；每帧 `link_mgr_on_frame` → 执行断开 → `cmd_disp_handle` → `CMD_RES_REPLY` 时 `bt_spp_write(..., 200 ms)`。
- 持久化：`reply.b_whitelist_changed` 或角色由 PHONE/PENDING 变为 ALARM 时，`link_mgr_whitelist_get` + `store_set_alarms`。
- 心跳：记录报警器电量/本地状态供 `status` 显示。
- 单一所有者：`link_mgr/cmd_ctx/alarm_src` 仅在链路任务内访问（组合根初始化发生在任务创建前）；控制台通过静态命令队列投递，链路任务执行后 `xTaskNotifyGive` 唤醒控制台。
- 时间：`(uint32_t)(esp_timer_get_time() / 1000)`，注释说明约 49.7 天回绕，比较均用无符号差值。
- 控制台命令：`status`、`alarm set/clear`、`pair`、`wl clear`、`sn <str>`、`policy`。`status` 打印会话（handle/角色/MAC）、白名单、配对状态、报警状态与心跳、解析错误计数、空闲/最小空闲堆、link 任务栈高水位。
