## 2. 实现要点

- CRC-32 采用逐位算法（反射多项式 `0xEDB88320`，初值取反、结果取反），任务 §实现要点明确允许“或逐位算法”。单帧 ≤ 280 B，无需 1 KB 查表。`crc32("123456789") = 0xCBF43926` 由验收测试验证。
- 多字节字段全部按小端逐字节组装（`read_u16_le`/`read_u32_le`/`write_u16_le`/`write_u32_le`），未对缓冲区做强转。
- 解析器查表状态：`pos`/`expect` 常驻；头长非 `0x14` 或 payload > 256 时 `len_errors++` 并复位；CRC 错误时 `crc_errors++` 并复位；不回扫已收字节。
- 为满足 clang-tidy `readability-function-size`（≤100 行），`proto_parser_feed` 拆分为 `parser_sync_byte`、`parser_check_lengths`、`parser_finish` 三个 `static` 辅助函数；状态机语义不变。
- 无动态内存、无时钟调用、无 IDF 头文件。
