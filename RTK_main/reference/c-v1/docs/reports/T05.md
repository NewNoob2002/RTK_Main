## 2. 实现要点

- 命名空间 `"rtk"`；键 `"sn"`（字符串）、`"alarm_wl"`（blob，n×6）。
- `store_init`：`nvs_flash_init` 遇 `ESP_ERR_NVS_NO_FREE_PAGES` / `ESP_ERR_NVS_NEW_VERSION_FOUND` 时记录 WARNING、`nvs_flash_erase()` 后重试一次；只擦 nvs 分区。
- 每次操作 `nvs_open` → 操作 → `nvs_close`；写操作成功后 `nvs_commit`。
- `store_get_alarms`：先以 `NULL` 查询 blob 长度；长度非 6 的倍数或 > `STORE_ALARM_MAX×6` 返回 `ESP_ERR_INVALID_SIZE` 且 `*p_count=0`；键或命名空间不存在视为空白名单（`ESP_OK`）。
- `store_set_sn`：空串或长度 > `STORE_SN_MAX` 返回 `ESP_ERR_INVALID_ARG`。
- `store_set_alarms`：`count=0` 删除键（键不存在视为成功）；`count > STORE_ALARM_MAX` 拒绝。
- 未使用动态内存；所有返回值检查。
