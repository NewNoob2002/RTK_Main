# C5a2 遗留清理报告

基线提交：`2f78b0e`（C5a Architect 验收提交）。硬件在环验收（HIL）未在本阶段执行，仍沿用 `docs/reports/C5a.md` 所列外场待测项。

## 逐项改动与取舍

1. **`gnss out rtcm` 与 `gnss base` 按接收机族过滤（第 1 项）**
   - 改动：`main/modules/gnss/GnssBaseConfig.{hpp,cpp}` 新增 `isBaseRtcmSupportedForFamily()` 与 `baseRtcmFamilyTag()`（`1033` 仅对 `Family::kUnicore` 或 `kUnknown` 支持、`1230` 仅对 `Family::kUblox` 或 `kUnknown` 支持）；`main/modules/gnss/GnssCmdsMode.cpp` 提取共享辅助 `printBaseRtcmRows()` 同时服务 `gnss out rtcm`（`show`/`default`）与无参 `gnss base`。
   - 行为：已探测接收机族时只展示该族会实际下发的 RTCM 项；未探测（`kUnknown`）时两条均展示并标注 `(Unicore)` / `(u-blox)`；对不适用报文执行 `gnss out rtcm <id> <rate>` 直接返回 `ERR <id> is not supported by this receiver`，不投递任务、不写 NVS。NVS 布局与缺省值保持不变。

2. **`gnss.base` 持久化迁回 `kIo`（第 2 项）**
   - 改动：`main/def/GnssSubDef.hpp` 紧接 `GnssSubVerb::kMode = 9` 新增 `GnssSubVerb::kSetBase = 10` 及子包类型 `BasePatchKind`；`main/modules/gnss/GnssModuleCmds.cpp` 扩展 `static_assert` 确保与 `GnssMaintenanceVerb`（`6..8`）不重叠并在 `kMode` 同级分支分发到 `GnssModule::cmdSetBase()`；新增纯头文件 `main/modules/gnss/GnssCmdPack.hpp` 供控制台命令与主机测试共用命令打包；移除 `GnssCmdsMode.cpp` 中在 console 线程直接写内存和调用 `storage.saveKeys()` 的 `persistBaseKeys()`，改为经 `submitRawTo(*appContext().ioExecutor, ...)` 同步等待 `kIo` 返回 `CommandResult`。
   - 分包取舍：`GnssBaseConfig` 全量编码共 41 B，超出 `fw::kCommandArgBytes`（32 B），因此按控制台实际修改块在 `args[0]` 携带 `BasePatchKind` 拆为 4 类原子子包：
     - `kMode`（2 B）：`[0]=0, [1]=WorkModeKind`，仅保存 `gnss/mode`（1 键）。
     - `kSurvey`（8 B）：`[0]=1, [1]=BaseType::kSurvey, [2..3]=svyS, [4..5]=svyAccCm, [6..7]=svyToS`，仅保存 `base_type..svy_to_s`（4 键）。
     - `kFixed`（22 B）：`[0]=2, [1]=BaseType::kFixed, [2..9]=fixLatE9, [10..17]=fixLonE9, [18..21]=fixHeightMm`，保存 `base_type` 与 `fix_lat..fix_h_mm`（4 键）。
     - `kRtcm`（14 B）：`[0]=3, [1]=msm, [2..13]=rtcmOut[12]`，仅保存 `rtcm_out..msm`（2 键）。
     - `GnssModule::cmdSetBase()` 校验范围后先备份 `prev`，写入内存并按子包切片调 `ctx().storage.saveKeys()`；若 NVS 写失败则回滚内存配置并返回底层存储错误码。

3. **`gnss.base` load/save 表驱动重构（第 3 项）**
   - 改动：`main/modules/gnss/GnssModuleMode.cpp` 以 `BaseFieldDesc` 静态描述表（`kBaseFieldDescs[10]`，覆盖键索引、编码类别、范围与成员指针）+ `decodeBaseField` / `decodeBaseBlobField` / `assignBaseField` / `encodeBaseField` 实现 `GnssModule::loadBaseAt()` 与 `GnssModule::saveBaseAt()`；`main/modules/gnss/GnssModule.hpp` 与 `main/modules/gnss/GnssKeys.hpp` 将原 20 个独立 `loadBase*`/`saveBase*` 函数替换为保持 `fw::StoreBinding` 签名的零状态模板包装 `loadBaseSlot<Slot>` / `saveBaseSlot<Slot>`。
   - 取舍：保留原 `GnssBaseConfig` 逐字节小端编码、标量边界与 `fix_*` 固定 blob 长度校验（`8/8/4`）、以及损坏键不污染默认值并按 `base_loaded_mask_` 回退缺失项的行为不变；由新增 NVS 全表往返与越界输入主机测试证明等价性。

4. **`BaseRtcmRing` 分段 `std::memcpy`（第 4 项）**
   - 改动：`main/data/BaseRtcmRing.hpp` 以 `writeLocked(std::span<const uint8_t>)` 与 `readLocked(std::span<uint8_t>)` 替换锁内逐字节循环 `writeByteLocked`/`readByteLocked`，每段读写最多执行两次 `std::memcpy`（按 `std::min(len, kCap - pos)` 处理环形回绕）。整帧写入、满环丢整帧计数与损坏头部清环语义完全保留。

5. **探测与配置发送日志区分 ASCII 与二进制十六进制（第 5 项）**
   - 改动：新增纯辅助头 `main/modules/gnss/GnssTxLog.hpp`（`printableAsciiTxLen()`、`formatGnssTxLog()`），`main/modules/gnss/GnssModuleProbe.cpp` 的 `applyWriteAction()` 改调 `formatGnssTxLog()` 输出 `%s TX %s`（`<probe>`/`<cfg>`）。
   - 取舍：去除尾部 `\r`/`\n` 后若非空且全为可打印 ASCII（`0x20..0x7E`），保持 `TX "<text>"` 格式；否则保留原始发送长度，对 UBX（`B5 62` 且长度 ≥ 4）按 `UBX 0x<cls> 0x<id>, <N> bytes: <hex...>`、其余按 `<N> bytes: <hex...>` 输出，最多打印前 16 字节并在超出时追加 `...`。

6. **命令入口集成主机测试（第 6 项）**
   - 改动：`GnssCmds.cpp` 与 `GnssCmdsMaintenance.cpp` 统一改用 `GnssCmdPack.hpp` 中的 `packGnss*` 函数打包；`tools/main_host_check/GnssResetCheck.cpp` 与 `GnssOutputCheck.cpp` 新增 `testBaseKeysTableRoundTrip()` 与 `testConsoleCommandDispatch()`，直接将 `packGnss*` 产物投入 `GnssModule::onCommand()` 并驱动 `FakeUART` + 内存 NVS 断言 `kSetBase` 4 种子包、`gnss mode base`、`gnss out`、`gnss config`、`gnss baud`、`gnss save`、`gnss freset` 各自命中真实处理分支；`tools/main_host_check/GnssModeCheck.cpp` 补充第 1、4、5 项单元测试。
