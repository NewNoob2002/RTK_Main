# T3 上板验证报告（ADR-0009）

日期：2026-11-12。板：RTK /dev/ttyACM0（ESP32 rev3，额定 240 MHz，40 MHz 晶振，Fudan 8 MB flash，CH9102 USB 串口）；
报警器 /dev/ttyUSB0（rtk_spp_peer，白名单在线）。负载：`tools/hil/spp_rtcm_mix.py --scan --seed 7`（RTCM 2k/5k/10k/20k/40k B/s 各 10 s + 产品请求 20 Hz、8 在途），
控制台由同一会话全程记录（`debug list`/`sys tasks`/`sys heap`/`status rtcm` 在结束时读取）。

## 1. 追踪输出瓶颈与修复（dbcbe37）

IDF v6.1 `uart_vfs.c:227` 的 `uart_write` 每字符调用一次 `uart_write_bytes`，printf 在 2 Mbaud 下只有约 15 KB/s。
trace_out 改为整行格式化后一次 `uart_write_bytes`。

| 构建 | 追踪 | 环 pushed / dropped | max_depth | RTCM（板端 = 主机） | 产品请求 | rx_dropped |
|---|---|---|---|---|---|---|
| 修复前（160 MHz -Os） | 7 类全开 | 5841 / 1280 | 256 | 帧/字节/CRC32 一致 | 1000/1000 | 0 |
| 修复后（160 MHz -Os） | 7 类全开 | 6811 / 0 | 45 | 一致 | 全部成功 | 0 |
| 修复后（240 MHz -O2 QIO 80M） | 7 类全开 | 6850 / 0 | 16 | 一致（3480 帧 616,688 B） | 1000/1000 | 0 |
| 修复后（240 MHz -O2 QIO 80M） | 全关 | 8 / 0 | 3 | 一致（3750 帧 669,877 B） | 1002/1002 | 0 |

结论：追踪开/关都不影响数据通路（0 丢、CRC 一致）；40 KB/s 档实际 24–30 KB/s，受 RFCOMM 空口限制，随次波动。

## 6. T2 控制台上板核对（对照 `docs/reports/T2.md` §4）

构建 `builds/out`（含统一输出出口与未知命令包装），逐条实测：

- `help`、`help wl`、`help nosuch`（`ERR unknown group`）、`status`/`status link|rtcm|sys`、`sys info|heap|tasks`、`sys`/`sys foo`（usage + `ERR usage`）、
  `bt list|policy`、`bt pair 30`（`ERR only 60s supported`）、`bt pair`（窗口打开，`bt list` 显示 open）、`wl list`、`wl add zz`/`wl del zz`（`ERR bad MAC`）、
  `wl add 11:22:33:44:55:66`（`ERR not supported`，T2 已列为后续项）、`alarm show|set 1 2|set 9 9`（`ERR state 0-2`）`|clear`、`store show`、`store sn`（usage ERR）、
  `rtcm stats|reset`、`log level spp_srv W/I`、`log level * X`（`ERR level E|W|I|N`）：结构与 T2 §4 一致，每条以 `OK`/`ERR …` 结尾。
- `status rtcm` / `rtcm stats` 含 ADR-0006 §2 逐字 `rtcm:` 与 `stats:` 行，`spp_rtcm_mix.py` 实测解析正常（§5 的 scan）。
- `sys reboot`：先回 `OK`，同一串口会话内重启后 `sys info` 显示 `reset_reason software`。
- 差异：`help` 各组说明文字与 T2 推演稿不同（实现为准，非契约）；`status` 概览 policy 显示 `CONCURRENT`（默认策略，推演稿写的 preempt 为示例）。
- 发现并修复：旧顶层命令与任意未知命令只打印 IDF 的 `Unrecognized command`、没有 `ERR`。改为 `--wrap=esp_console_run` 输出 `ERR unknown command`（ADR-0009 §2.8）。
  `pair`、`policy`、`sn`、`foo bar` 均已验证为 `ERR unknown command`；空行仍只回提示符。
