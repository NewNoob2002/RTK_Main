## 2. 实现与接口定稿

- legacy 保留 2B 小端长度头、至少两条最大记录的容量校验、复制式 read、统计和原非二次幂 u32 回绕路径；typed 独立初始化，容量为二次幂且小于 2^31，至少容纳 `max_record+3`，负载长度 1..65535。
- typed 记录为 2B 小端长度 + 1B type（0..31）+ payload。32bit mask 支持 0；无匹配在线读者时不写入，返回 `kOk` 并计 `no_subscriber`。无 pin 时仍整条覆盖；筛除计 `filtered`，覆盖订阅记录计 reader `dropped`。
- `peek` 返回整条负载的至多两段只读 span 和 `{generation,serial,reader_id}`；每 id 最多一个 pin。`commit` 消费整条，`cancel` 不消费。有租约时 detach/set_mask 返回 `kBusy`；过期/重复/错误 token 返回 `kInvalidArg`，不改变当前租约。
- 写者先锁内检查全部 pin。若改写区触及任意 pin，立即整条 `kBusy`，计 writer 和匹配在线读者 `pinned_drop`，不提前淘汰任何记录。成功后保留改写窗口，逐条淘汰并逐次释放锁；新 peek 若处于待覆盖前缀，逐条协助淘汰后才可 pin。
- header/payload 写入已保留空闲区域时不持锁，head 保持未发布；最后锁内一次发布。读者只能访问已发布记录。预留窗口防止检查 pin 后又有新 pin 进入改写区域；这也是 payload 锁外复制成立的关键约束。
- typed 的二次幂索引在 u32 回绕前后映射相同，不执行 legacy 的存储旋转。无 pin 的旧记录可被覆盖，较新的 pin span 即使遇到 head/oldest 回绕仍保持地址和内容。
- 耗尽策略已定稿：serial 达 `UINT32_MAX` 后不再生成新租约，peek 返回 `kInvalidState`，需 detach/attach 换 generation；generation 达 `UINT32_MAX` 的槽在 detach 后永久退役；空闲槽均退役时 attach 返回 `kInvalidState`。不循环复用 token。销毁对象前须任务/租约静止，丢弃所有 token，禁止旧 token 跨重建对象使用。
- legacy/typed 专用方法混用返回 `kNotSupported`；detach 与 base stats 共用，typed 扩展统计独立。调用方须遵守单写者/每 id 单读者、初始化完成后再并发、存储与输入不重叠。跨任务须提供有效 LockOps，`kNoLock` 仅用于单线程/外部串行化。

没有偏离 ADR-0011 §5 的方法签名或 Result 集合。类布局变化只承诺重编译后的源码兼容。BT 的总量 ≤4096B 有界复制、不跨等待的租约约束已写入契约；本卡不接入 BT/main，不声称已验证业务吞吐或板上时间。

## 3. 临界区与资源

typed 长负载的复制全部在锁外；每个临界区最多处理一条记录的 3B 头和最多 4 个读者，或者最多三轮各 4 个读者的元数据扫描/计数（订阅检查、pin 检查、冲突时的匹配读者计数）。attach 清零一个 44B Reader；统计快照目标端最大 32B、host 最大 40B。没有持锁 payload 复制、环存储旋转、RTOS/IO 或堆分配。保守按整个对象 304B 的元数据规模计仍小于 1KiB，且实际操作只触及子集。

淘汰/过滤多条记录时每条释放锁，临界区长度不随 payload 或淘汰数量增长。单次完整调用可能取得多次锁，例如满 4KiB 环中的最小 4B 记录可导致一次 4093B 写入淘汰 1024 条，但不会把这些操作合并到一个 portMUX 临界区。该结论来自源码工作量审查与受控调度测试；未测量硬件微秒数。legacy 原有持锁复制/旋转路径保持原行为，新的 typed 临界区上限不追溯修改 legacy。
