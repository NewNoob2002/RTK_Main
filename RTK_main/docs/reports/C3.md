# C3 启动早期配置与失败回退

基线 `a2d70a1`。实现范围对应 C3 任务卡及 ADR-0014 §2.2、§2.3、§2.7。

## 实现

| 文件 | 改动 |
| --- | --- |
| `main/app/BootConfig.{hpp,cpp}`、`main/AppContext.hpp`、`main/CMakeLists.txt` | 新增由 `constinit AppContext` 持有的纯值启动快照。早期初始化 NVS，读取和校验 `dbg/{mask,report,hex,loglv}` 及启用 GNSS 时的 `gnss/baud`，对越界值记录键名和原值。 |
| `main/app/BootFlow.cpp` | 在横幅后执行 `earlyConfig`。消费者通过启动屏障并进入 `kRunning` 后清零 `boot/fails`，随后输出启动摘要。此时所有可失败的启动步骤已完成。 |
| `main/modules/debug/DebugKeys.hpp`、`DebugModule.{hpp,cpp}` | 早期应用日志级别、trace 掩码、十六进制掩码及报告周期。追踪关闭的固件仍可应用文本日志级别。环安装沿用已应用的设置。 |
| `main/modules/storage/{StorageModule,StoreKeys}.{hpp,cpp}`、`ConfigCmds.cpp` | 存储阶段复用早期 NVS 初始化与加载计数，仅装载剩余目录键。保留 C1 分组摘要及共用的键值格式化。普通模式下详细日志仍可展示盘上原值。安全缺省时启动摘要及逐键明细均显示缺省，`config` 显示 `boot_mode = safe defaults`。 |
| `main/modules/gnss/GnssKeys.hpp`、`GnssModule.{hpp,cpp}`、`GnssModule{Cmds,Probe}.cpp` | UART 初始速率与控制器首个候选一致，来源为早期快照或 Kconfig。安全缺省时抑制自动探测缓存写入，显式的 `gnss rate` 和 `gnss out` 只写各自的键。 |
| `tools/main_host_check/{CMakeLists.txt,MainHostCheck.cpp,GnssResetCheck.cpp}` | 覆盖无旧计数及旧计数 2/3、增量与清零、诊断越界告警、存储阶段保留早期值、NVS 初始化失败和安全模式显示。GNSS 回归同时检查 UART 初始速率取自启动快照。 |

`boot/fails` 以 u8 饱和递增。读到非零旧值时记录 `Previous boot did not complete (N)`，旧值达到 3 时额外记录回退 W。本次启动跳过用户配置和探测缓存，保留出厂身份及独立的运行期用户数据（白名单、蓝牙绑定）。安全缺省模式允许用户显式写入配置，新值在下次正常启动生效。计数写失败只告警。用户 NVS 初始化失败时沿用缺省值，仍尝试加载可用的出厂 SN。
