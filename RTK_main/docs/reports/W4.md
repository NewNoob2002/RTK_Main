## 2. 页面结构与与旧页面的差异

### 页面结构
1. 顶部栏：设备蓝牙名标题 + WebSocket 连接状态指示灯（绿/黄/红）。
2. 状态横幅：断线重连提示；收到 `bye` 后显示“设备已切回蓝牙模式，可以关闭本页”（或出厂恢复提示）并停止重连。
3. 可折叠分组卡片：
   - **设备信息**：板型、固件版本、SN、蓝牙名称、射频模式、运行时间、空闲堆（含历史最低）、复位原因。
   - **GNSS 配置与状态**：状态、型号/固件、定位类型、卫星数、hAcc、实际输出频率；定位频率（1/2/5/10/20 Hz）、GGA/GSA/GSV/GST/RMC 周期（0/50/100/200/500/1000 ms）、星座勾选（`config` 无 `gnss.const.*` 时自动隐藏）、保存按钮、行内结果提示。
   - **蓝牙白名单与配对**：MAC 白名单列表（含逐条删除）、添加输入框、下次蓝牙启动打开配对窗口开关、行内结果提示。
   - **工厂配置**：`hello.factory=false` 时仅显示解锁口令框；解锁后显示 `factory.sn` 写入与“恢复出厂设置”（带确认弹窗）。
   - **系统与退出**：板型/固件/控制台档位、退出网页配置并切回蓝牙模式按钮。

### 与旧页面（`AP-Config/`）的差异
- **零外部依赖**：去除 bootstrap 与 jQuery，手写原生 HTML/CSS/JS，离线直接可用。
- **协议升级**：由旧版平铺 CSV 改为 `docs/web/ws-protocol.md` v1 JSON 帧（`hello` / `config` / `status` / `ack` / `bye`），请求严格串行（等 `ack` 后发下一条）。
- **第一版范围**：按 ADR-0017 §2.6 / Q4，不含 OTA 固件上传；新增蓝牙白名单管理、配对窗口、工厂解锁隔离。
