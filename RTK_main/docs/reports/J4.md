## 2. 关键实现说明

1. **`btrc::Reconnector`（`components/bt_reconnect/src/reconnect.cpp`）**
   - `configure` 校验 `jitter_pct <= kMaxJitterPct`、`sdp_after_failures != 0`、`backoff_min_ms <= backoff_max_ms` 及 6 个时长字段全部非 0；`seed == 0` 时回退 `kDefaultSeed`，防止 xorshift32 锁死在 0。
   - 快速窗口内（`backoff_ms_ == 0` 且 `now_ms - window_start_ms_ < fast_window_ms`）固定基数 `fast_retry_ms`，窗口外按 `backoff_min_ms` 起翻倍封顶至 `backoff_max_ms`；随后对 `delay` 乘以 `[100 - jitter_pct, 100 + jitter_pct]%` 均匀整数比例。
   - `on_close` 在线满 `stable_online_ms` 才复位 `backoff_ms_` 与重开 `window_start_ms_`，短于该时长保留当前退避与原窗口起点，避免连上即断触发快速重试风暴。
   - 缓存 SCN 在连续 `sdp_after_failures` 次 connect 失败（或 `kConnecting` 超时）后清除；`on_open` 时清零连续失败计数。`stop()` 进入 `kStopped` 后所有事件仅更新统计，不产生动作与状态迁移。所有时间差采用 `uint32_t` 无符号减法处理回绕。

2. **`app::FanoutRing`（`components/app_fw/src/fanout_ring.cpp`）**
   - 2 字节小端长度头 + 负载按字节环形存储，读写均通过 `std::span` 支持跨越物理缓冲末尾回绕。
   - 空间不足时淘汰最旧记录；淘汰期间同步将尚处于被淘汰记录起点的已登记读者推进至下一条记录并累加 `dropped`，使全部读者 `tail` 始终保持在 `[oldest_, head_]` 记录边界内，从而保证 `head_ - tail <= cap_ < 2^31`。
   - 当 `oldest_` 跨越 `2^32` 且 `cap_` 非 `2^32` 约数（例如非 2 的幂的最小容量 `2 * (65535 + 2) = 131074`）时，在锁保护下原地旋转对齐残留有效区间至 `new_oldest % cap_`，消除跨回绕物理索引跳变。

3. **`test_apps/rtk_spp_peer` 接入**
   - `peer.c` 保持 C 语言不变，通过 `reconnect_bridge.{h,cpp}` 使用 `btrc::Reconnector`；全部重连动作均在 `worker` 单任务执行。
   - 启动时从 `esp_random()` 注入随机种子，从 NVS namespace `"peer"` / key `"target"` 读取 6 字节 MAC；在收到 `ESP_SPP_INIT_EVT` 成功事件后自动启动重连流程，避免蓝牙协议栈未就绪前调用 `esp_spp_start_discovery`。
   - `connect MAC` 保存目标到 NVS（若当前已连向另一 MAC 则先断开旧句柄再启动新目标）；`reconnect stop|start|status` 分别停止重连、启动重连、打印状态名 / `target` / `next_attempt_in` / 全部 `Stats`；原有 `stop` 与无参数 `reconnect` 语义保持不变。
