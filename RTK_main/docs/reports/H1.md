## 契约核对

- `init` 校验解码器数 1..8、描述符非空、name/first_byte/step 非空、max_frame 在 1..65535、缓冲区足够容纳每个解码器。失败时清空解析状态、配置和统计，实例回到未初始化状态；未初始化的 feed/abort 返回 kInvalidArg。
- init 先检查回调防重入，再修改状态；两个 Sink 回调内的 init/feed/abort 均返回 kReentry，保持原解析状态和回调数据有效。
- init 为每个解码器调用 256 次 first_byte 建立位图；后续 feed/abort 不再调用 first_byte。空闲字节只查位图，累积按 need 整段 memcpy，凑足后才 step。
- 同首字节的候选按下标优先级尝试；拒绝后从前缀 1 回放，按 need 增长前缀。中途成帧时先输出之前的未知字节，再输出帧，回调结束后用 memmove 处理剩余缓冲区。
- 每次拒绝缩小当前候选集合或前移起点；未知字节合并输出，所有输入按流顺序恰好归属一帧或未知字节。
- need == 0、超过 max_frame、未识别的 Step 值都按拒绝处理；超过缓冲容量另计 overflows。长度检查采用减法，避免 SIZE_MAX 造成加法回绕。
- abort 保留已拒绝候选集合，直接拒绝当前半帧，尝试其他候选和后续起点；回放成帧照常输出，最终回到空闲。空闲 abort 不增加 aborts。
- 只包含 demux/demux.hpp、algorithm、cstring；使用 span 切片表达边界。无堆、无递归、无 VLA、无浮点，无缓冲区大小级别的栈数组；描述符和初始化后的位图不被写。
- 源码包含任务卡要求的工具/模型和人工负责人注释；每处 static_cast 都有范围或低位统计解释；公共函数定义注明线程/ISR 约束。

### H1 自测内容

固定种子 `0x17C0FFEE`，1000 组随机流分别以整块、逐字节、随机 1..17 字节三种方式喂入，最后 abort。独立 oracle 直接按四个自定义协议的字节规则分类，不复用 Engine 或其回放控制流。逐回调检查原输入内容与顺序、每字节协议归属、字节守恒、缓冲区两侧哨兵、描述符身份、回调内三 API 防重入及重入失败后的数据有效性。

固定案例额外检查全部 init 参数分支、失败 init 后不可用、默认构造及 constinit 实例未初始化调用、同首字节冲突、中途成帧和尾部回放、abort 恢复较低优先级帧、统计清零保留半帧、默认 on_unknown、第八个位图候选、StaticDemux 定长与 index_of、need 为 0/超 max_frame/超容量/SIZE_MAX。六字节帧逐字节喂入只调用两次 step，验证按 need 批量累积。

两个自测程序实际输出：

```text
H1 selftest PASS: API, replay, abort, reentry, invalid need, batching, 1000 streams x 3 chunk modes
```
