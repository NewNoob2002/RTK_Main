## 2 接口摘要

```cpp
namespace web {

enum class ErrorCode : uint8_t { kNone, kBadJson, kTooLong, kUnknownKey, kBadValue,
                                 kLocked, kBusy, kUnsupported, kFailed, kTimeout };
const char *toString(ErrorCode) noexcept;          // "bad_json"…，"ok"
ErrorCode fromResult(fw::Result) noexcept;         // Ok→None, InvalidArg→BadValue,
                                                   // Busy/NotSupported/Timeout 直映，其余→Failed

enum class RequestType : uint8_t { kSet, kCmd, kUnlock };
struct Request {                                   // 不可复制：视图可能指向内部解码缓冲
    RequestType type; uint16_t id;
    std::string_view key, value;                   // set
    std::string_view name;                         // cmd
    std::string_view token;                        // unlock
};
ErrorCode parseRequest(std::span<const char> frame, Request &out) noexcept;

class JsonWriter {
    bool beginObject(); bool beginNested(std::string_view key); bool endNested();
    bool endObject();
    bool writeInt(std::string_view key, int32_t value);
    bool writeBool(std::string_view key, bool value);
    bool writeString(std::string_view key, std::string_view value);
    bool writeStringArray(std::string_view key, std::span<const std::string_view> values);
    size_t finish(std::span<char> out);            // 0 = 失败；>0 = 帧字节数
    void clear();
};

enum class KeyKind : uint8_t { kEnum, kMac, kSn, kBool };
struct KeySpec { std::string_view name; KeyKind kind; std::span<const int32_t> allowed;
                 bool needsUnlock; bool optional; };
const KeySpec *findKey(std::string_view) noexcept; // nullptr = unknown_key
ErrorCode validateValue(const KeySpec &, std::string_view text, CanonicalValue &out) noexcept;

} // namespace web
```

解析语义：

- 单帧 > 1024 B → `kTooLong`（先检查长度）；非对象、嵌套、浮点、重复键、缺字段、字段类型不符、未知 `t` → `kBadJson`；`id` 不在 1..65535 → `kBadValue`。
- 未知顶层字段按协议忽略（向前兼容）；重复的未知字段也拒绝。
- 字符串只接受 `\"` `\\` `\/` `\b` `\f` `\n` `\r` `\t`，不支持 `\uXXXX`；裸控制字符拒绝。
- 无转义字段的 `string_view` 直接指向输入帧；含转义字段解码到 `Request` 内部 1024 B 缓冲（无堆），因此 `Request` 禁止复制/移动。

键表：`gnss.rate` 1/2/5/10/20；`gnss.out.{gga,gsa,gsv,gst,rmc}` 0/50/100/200/500/1000；`gnss.const.{gps,bds,glo,gal}` 0/1 且 `optional=true`（W0 结论决定 v1 是否提供）；`bt.wl.add/del` MAC；`bt.pair_next` 0/1；`factory.sn` 1–16 个 `[0-9A-Za-z-]` 且 `needsUnlock=true`。校验产物 `CanonicalValue`：枚举/布尔为 `int32`，MAC 为 6 字节、SN 为字符字节串。

## 6 与契约的偏离

1. 任务卡 §1.4 明确“转成 `fw::Command` 不在本卡”，因此未实现；ADR-0017 §2.5 的该句由 W5 在 `main` 完成。
2. `JsonWriter::finish()` 返回 `size_t`（0 = 失败）而非 `bool`，因为 WebSocket 发送方必须拿到帧长度；语义仍是“失败不写调用方缓冲”。
3. 含转义的字符串字段解码到 `Request` 私有缓冲（帧内无转义时仍零拷贝指向输入）；这是为满足“无堆 + 可接受 `\"`/`\\`”的最小代价。`Request` 因此不可复制/移动。
