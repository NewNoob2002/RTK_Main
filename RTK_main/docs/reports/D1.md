# D1 控制台构建档位

D1 已实现，基线为 `dd00492`。使用 ESP-IDF v6.1 构建，完整离线门禁 33 项全部通过。PRODUCTION 固件保留诊断和隐藏工厂命令，NONE 固件保留 UART0 日志直写路径，REPL 和 linenoise 已从 ELF 裁掉。P2 台架验收和启动后空闲堆待 Architect 测量。

## ADR-0016 §3 尺寸

DRAM 采用 `idf.py size` 的 DRAM 用量（.data + .bss）。镜像列采用该工具的 Total image size，括号内为 `stat` 读取的实际 `rtk_main.bin` 文件大小。PRODUCTION、NONE 使用各自的 trace-off 叠加文件。

| 构建 | DRAM 静态 | Flash code | Flash data | 镜像 | 启动后空闲堆 |
|---|---:|---:|---:|---:|---|
| dev（默认） | 73,647 B | 600,180 B | 161,304 B | 869,586 B（869,696 B） | NOT_RUN |
| production | 73,239 B | 575,032 B | 148,776 B | 831,910 B（832,032 B） | NOT_RUN |
| console-none | 71,199 B | 537,988 B | 138,144 B | 784,034 B（784,144 B） | NOT_RUN |
