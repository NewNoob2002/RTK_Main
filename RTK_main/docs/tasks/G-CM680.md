# G-CM680 — CM680 接收机识别（Unicore 兼容）

- 依据：ADR-0012 §2.9（2026-11-18 修订）、ADR-0015（P2 v1.41 板载 CM680）
- 基线：a2deda2 + Architect 本卡提交（`Model::kCm680` 已追加、frozen 已重算）
- 实现：codex；Architect（Claude）验收、实板 HIL、提交、重算 frozen

## 1. 目标

1. `components/stream_demux/src/decoders/UnicoreHash.cpp`：CRC 形式（`*` 后 8 位十六进制）先按现有范围
   （`#` 之后到 `*` 之前）校验；不符时再按含首字节 `#` 的范围（`#` 到 `*` 之前）校验，任一相符即成帧。
   两者都不符时 `received` / `computed` 仍报现有范围的值（日志与现有用例不变）。XOR 形式不变。
   更新文件头注释说明两种覆盖范围及来源（ADR-0012 §2.9）。不得新增静态可变状态；仍 ISR 安全、无堆。
2. `components/gnss`：`Model::kCm680` 接入所有按型号分支的地方：
   - `modelName()` → `"CM680"`；`familyOf()` → `kUnicore`；`modelFromU8()` 接受其值（6）。
   - `UnicoreReceiver.cpp` `modelFromText()`：精确匹配 `"CM680"` → `kCm680`（放在 `UM9` 前缀判断之前或之后均可，
     但不得把其它 `CM` 开头文本识别为 CM680）。
   - 能力表 `caps()` 与 `forModel()`：`kCm680` 与 `kUm980` 相同（`forModel` 返回 `kUm980Receiver`）。
   - 其它对 `Model` 做 `switch` 的位置（`rg -n 'Model::kUm980' components main`）逐一补齐，不留 `default` 吞掉新值造成行为差异。
3. main 侧如有按型号显示/判断的代码（状态输出、NVS 读回上界、GnssService 型号码等），确认 `kCm680` 走通；
   协议上报的型号码若有映射表，追加 CM680 并在报告里写出取值。
4. 不改 frozen 文件（`gnss/Types.hpp` 已由 Architect 改好）；不改 ADR；BT 名、启动流程不动。
